# lab-server

Локальный сервер измерений, обработки сигналов и управления лабораторными приборами.
Клиенты подключаются по TCP или WebSocket. Графики, Steel REPL и сценарии остаются на стороне lab-plot.
Сервер принимает команды сценариев как обычные TCP-запросы.

- Физические приборы Arduino и МЕТАКОН 513/523/533, предварительные драйверы РРГ-12
  и Erstevak MTM9D-KF25, виртуальный ThermalPlant.
- Каталог сигналов, чтение, запись, подписки и диагностика состояния.
- Компоненты EMA и PID, привязка контроллера к выходу и управление правом записи.
- Внешний TOML эксперимента с явной командой Save, необязательная запись измерений и аудита в SQLite.

## Быстрый запуск без оборудования

Запустите сервер из корня репозитория.

~~~powershell
cargo run --release -- --config examples/virtual-plant-external.toml
~~~

ThermalPlant предоставляет три температуры и мощность. EMA запускается в Running,
PID — в Shadow. TCP слушает 127.0.0.1:7240, WebSocket — 127.0.0.1:7241.
Конфигурация загружает внешний TOML эксперимента и включает SQLite.
Для правок и Save сделайте копию основного файла и каталога `experiments` рядом с ним.

Другие варианты — [ThermalPlant со встроенными компонентами](examples/virtual-plant.toml)
и [TCP/WebSocket с пустым каталогом](examples/websocket.toml).

## Физические приборы

Настройте локальную копию [Arduino TOML](examples/arduino.toml) под свой COM-порт и параметры линии.
Передайте путь в `cargo run --release -- --config`. Пример [Arduino с EMA и PID](examples/processing.toml)
показывает настройку компонентов.

Для МЕТАКОН используйте [шаблон чтения](examples/metakon-readonly.toml).
Укажите фактический COM-порт, скорость, адрес и канал. Автоматические тесты драйвера
используют эмулятор. Подключение и поведение прибора проверяются отдельно.
[Инструкция проверки на физическом приборе](docs/metakon-hardware-test.md).

Для трёх МЕТАКОН и РРГ-12 есть [шаблон общей RS-485 для чтения](examples/rs485-readonly.toml)
с `bus_silence_ms = 20` на физическом порту. Фактические настройки и совместимость устройств
нужно подтвердить до подключения. РРГ-12 читает регистры по Modbus RTU. Erstevak читает давление
в mbar по Thyracont V1, поддержку которого нужно сверить с ревизией MTM9D-KF25.
[РРГ-12](docs/rrg12-driver.md) · [Erstevak и проверка общей шины](docs/erstevak-driver.md)

## Ограничения

TCP и WebSocket доступны только через loopback, клиентской авторизации нет.
COM-порты не переподключаются автоматически. ACK подтверждает результат команды по протоколу прибора.
Фактическое состояние проверяйте отдельно, а `outcome_unknown` не повторяйте автоматически.

Завершайте сервер через `Ctrl+C` и дождитесь выхода процесса. Автоматической записи безопасной
мощности при остановке нет. После запуска сохранённого эксперимента PID снова в Shadow.
